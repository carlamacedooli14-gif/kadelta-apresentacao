# Kadelta — Apresentação de Prospecção Ativa

Apresentação interativa para a equipe de prospecção ativa da Kadelta.

## Acessar
https://carlamacedooli14-gif.github.io/kadelta-apresentacao/

## Usar
Abra o site no celular ou computador. Alterne entre modo **Pitch** e **Completo**. Escolha a dor apresentada pelo cliente e consulte o **Guia de fala**. O botão PDF usa a impressão do navegador para salvar o material em PDF.

## Publicar
A publicação é acionada automaticamente ao atualizar a branch `main`, pela ação em `.github/workflows/deploy.yml`.

> Atenção: o conteúdo deste repositório é público, inclusive o guia de fala e campos comerciais. Não adicione dados de clientes, credenciais ou informações privadas.
